# 🛠 Explorer Rescue Robot
  Explorer Rescue Robot is designed for search and rescue missions, enabling operators to explore hazardous environments and receive real-time data to assist in decision-making.

## Features

- ✅ Real-time video transmission via FPV system
- ✅ Temperature and gas detection in surrounding areas
- ✅ Human motion detection for locating survivors
- ✅ Remote control via 2.4GHz Wireless Controller
- ✅ Equipped with thermal and PIR motion sensors
- ✅ Capable of navigating rough terrain and debris
